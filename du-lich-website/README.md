# Dự án Website Du Lịch

## Giới thiệu
Hệ thống **website** quản lý du lịch, hỗ trợ *quản lý khách hàng* và **_quy trình làm việc_** của chúng tôi

## Cấu trúc thư mục

| Thư mục | Nội dung |
| :--- | :--- |
| `data/` | Dữ liệu danh sách địa điểm du lịch |
| `logs/` | Dữ liệu nhật ký hoạt động và lỗi |
| `docs/` | Chứa các tài liệu lịch trình |

## Kiểm tra danh mục dự án
```powershell
Get-ChildItem -Recurse -Force
```
